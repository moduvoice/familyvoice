8. How it was run (staged)

Stage 1 (GPU, once per model): 16,371 utterances x 5 crops (1/2/3 s, 1-4 s, 1-4 s noisy) embedded in same-length batches of 128, decoding/cropping/noise on 8 CPU workers (18 s); r293 587 s, CAM++ 180 s, ReDimNet-B2 67 s, ReDimNet-B6 418 s; cached as npz and backed up to S3 tmp. Stage 2 (CPU only, no model): this grid of 684 cells / 684000 simulated families in one process pool: wall 17:28.93, CPU 720% of 800%, peak RSS 2718 MB, sampled CPU busy mean 96.2%.
